# Lorebound: achievement badges

The game has a new **Achievements** page at the bonfire. Each achievement needs a badge. Until the badges exist, the game shows the reverse of the matching level medallion as a stand-in.

Please make **one badge per achievement** in the same painted, dark-fantasy style as the earlier Lorebound packs (the level medallions, items and gear art).

## Format

- One transparent PNG per badge, **512 × 512**, with the badge filling about 80% of the square (leave a little transparent margin).
- File name: `ach-<id>.png`, using the ids below (for example `ach-first-blood.png`).
- Every badge should read clearly at **72 px** on a dark background: one bold central image, no small text and **no words or numbers** on the badge.
- Use the **frame metal** listed for each badge, so the badges match the six tiers of the level medallions. The game greys out badges that are not yet earned, so the colours should look good in full colour.
- Put them all in one zip with a `badges/` folder, plus a contact sheet and `preview.html` as before.
