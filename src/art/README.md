# Art (creatures, bonfire, title, world map)

These are the painted portraits used in the game. The copies here are the small previews Canva returned (about 300×400 after
upscaling). To get the full-resolution versions in, open each link below in Canva, download the image, and save it over the file
of the same name in this folder. Then ask Claude to rebuild, or run `python3 build.py` from the `src` folder.
